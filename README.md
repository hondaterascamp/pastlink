# PastLink

## サイト概要
### サイトテーマ
製造現場でのトラブル管理webアプリケーション。
過去のトラブル内容を蓄積し、トラブルを未然に防ぐ仕組みを提供するwebアプリケーション。
​
### テーマを選んだ理由
私はこれまで製造業に従事し、製造設備の点検や簡易メンテナンス、設備トラブルへの対応を経験してきました。
製造現場では、設備に不具合が発生した際、過去に同じような事例があっても、当時の状況や対応方法をすぐに確認できない場合があります。
また、対応した担当者しか詳細を把握していないと、経験や知識が十分に共有されないという課題が生じます。
そこで、過去の設備トラブルと対応履歴を一元管理し、必要な情報を簡単に検索できるWebアプリケーションを開発したいと考えました。
現場で培った経験を活かし、情報共有の効率化とトラブル対応の円滑化に貢献できるサービスを目指します。
​
### ターゲットユーザ

- 製造設備を使用する現場作業者(製造オペレーター)
- 製造ラインのリーダーや管理者
- 設備保全・メンテナンスの担当者
- 設備トラブルの対応履歴を共有したい製造現場のチーム
- 品質管理の担当者
​
### 主な利用シーン

- 設備トラブルが発生した際に、過去の類似事例を検索するとき
- 不具合の原因や実施した対応内容を記録するとき
- 交代勤務の担当者に、トラブルの状況や対応履歴を共有するとき
- 繰り返し発生する不具合の傾向を確認するとき
- 新しい担当者が過去の対応事例を参考にするとき
